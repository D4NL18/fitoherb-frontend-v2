# Objetivos — Módulo Home

> **Data de criação:** 23/09/2026

---

## Objetivo Principal

Ser a primeira impressão do visitante, comunicando a identidade e os diferenciais da Fitoherb Nordeste de forma visual e dinâmica.

## Objetivos Específicos

| Objetivo | Como é Atingido |
|----------|----------------|
| Impacto visual imediato | Carousel fullwidth com banners gerenciáveis pelo admin |
| Navegação intuitiva ao catálogo | Grid de categorias clicáveis com imagens vibrantes |
| Credibilidade com dados reais | Stats animados (28 anos, +1800 produtos, +2000 clientes) |
| Conversão para contato | CTA direto para `/contato` |
| Apresentação da empresa | Seção "Sobre" com link para `/quem-somos` |
| Conteúdo sempre atualizado | Banners e categorias carregados da API (não hard-coded) |
