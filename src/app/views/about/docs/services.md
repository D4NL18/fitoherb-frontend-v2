# Serviços — Módulo About

> **Data de criação:** 23/09/2026

---

O módulo About **não utiliza serviços externos**. Todo o conteúdo é estático e renderizado diretamente no template HTML. Não há chamadas à API neste módulo.

As animações de KPIs são controladas por Signals internos do componente (`stats.years`, `stats.products`, `stats.partners`, `stats.brands`).
