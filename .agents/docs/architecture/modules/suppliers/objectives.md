# Objetivos — Módulo Suppliers

> **Data de criação:** 23/09/2026

---

## Objetivo Principal

Apresentar os fornecedores parceiros da Fitoherb, valorizando os parceiros estratégicos e facilitando a navegação ao catálogo por fornecedor.

## Objetivos Específicos

| Objetivo | Como é Atingido |
|----------|----------------|
| Visibilidade dos parceiros | Grid com imagem e nome de todos os fornecedores |
| Priorização de parceiros estratégicos | Ordenação automática: `isHighlighted=true` primeiro |
| Navegação ao catálogo filtrado | Clique navega para `/produtos?supplier=<slug>` |
| Experiência visual fluida | Animação de entrada do grid ao rolar a página |
